# Living Dead TC 20개 작성

이번 요청으로 작성한 TC만 이 폴더에 모았다. 기존 TC나 다른 게임의 TC는 포함하지 않았다.

- [TC 20개와 실행 조건](test-cases.md)
- 대상: 현재 checkout의 Living Dead, Normal 및 Zombie 모드
- 작성일: 2026-11-11
- 적용 기준: `artel-skills/skills/artel-test-cases/SKILL.md` 및 runtime/few-shot reference
- 확인 범위: 게임 코드, Input Actions, Build Settings
- 실행 결과: **미실행**. 대상 빌드 ID 및 QA run은 지정되지 않았다.
- 작성 가능성: 20개 모두 **Needs build verification**. 코드에서 확인한 경로이며, 빌드에서 입력·관찰·기능 등록을 확인해야 한다.

ARTEL 프로젝트 17의 `2026-11-11 TC 20개` 폴더(ID 16)에 20개를 DRAFT로 저장했다. TC ID는 1869–1888이며, 재조회로 개수·본문·DRAFT 상태를 확인했다. 게임 실행은 수행하지 않았다. 실제 실행에서 준비 조건이나 관찰 수단이 없으면 BLOCKED로 남기며 PASS/FAIL로 추정하지 않는다.
